## 一、实验目的

## 三、实验整体逻辑分析

实验首先由 `dtb_init()` 解析 QEMU 传入的设备树，取得物理内存起始地址和大小；随后 `pmm_init()` 选择物理内存管理器，调用 `page_init()` 建立 Page 描述符数组并排除已经被 OpenSBI、内核镜像和描述符数组占用的区域；最后通过 `init_memmap()` 将连续空闲页交给分配器，并用分配器自带的 `check()` 验证分配和释放。

本次提交完成了负责模块 `page_init()`。Best-Fit 和 Buddy System 保留给对应成员在同一分支继续实现。

## 四、实验内容与实现

### 物理内存探测与 Page 描述符初始化

**负责人：** 2413603-常侯鑫

涉及文件：`code/kern/mm/pmm.c`、`code/kern/driver/dtb.c`、`code/kern/mm/pmm.h`、`code/kern/mm/memlayout.h`。

`page_init()` 完成以下工作：

1. 验证设备树报告的内存范围，并限制到框架定义的可管理上界。
2. 设置 `va_pa_offset`，计算管理上界的绝对物理页号 `npage`。
3. 按页对齐计算 Page 描述符数组的位置和大小。
4. 先将所有 Page 标记为 reserved，避免内核占用区域进入分配器。
5. 从描述符数组结束位置开始，将剩余完整页面交给 `init_memmap()`。

### 接口与规格（Spec）

函数签名为 `static void page_init(void)`，无参数、无返回值。前置条件是 `dtb_init()` 已解析设备树，且当前管理器的 `init()` 已运行。后置条件是完成 `va_pa_offset`、`npage`、`pages` 初始化，并仅向 `init_memmap()` 注册不与 OpenSBI、内核、描述符数组重叠的完整页面。

`npage` 表示管理区结束地址的绝对物理页号，描述符数量是 `npage - nbase`；`pages[0]` 对应 `DRAM_BASE`。硬件内存超过 `PHYSICAL_MEMORY_END` 时按框架上界截断；设备树范围无效、加法溢出或描述符空间不足时调用 `panic()`。没有完整空闲页时不调用 `init_memmap()`。

框架的 `nbase` 和启动映射固定对应 `DRAM_BASE`，因此本实现明确拒绝其他 RAM 起点，不宣称支持任意硬件布局。

补充测试编写时，一次试图用 `PADDR(end)` 构造描述符空间不足的输入，但该注入点位于 `va_pa_offset` 初始化之前，因此构造出的值不符合测试意图。后来改为显式的 2 MiB 内存上限来验证内存不足的拒绝路径。这是测试输入构造的修正，不能记录成内核实现的失败。最终没有声称已实测“描述符空间不足”和“恰好无完整空闲页”两条分支。

### 扩展思考：硬件内存范围如何获取

OS 可以通过固件约定获取内存布局：本实验由 QEMU / OpenSBI 启动链传入设备树地址，再解析 memory 节点的 reg 属性。其他平台也可能使用 UEFI 内存映射或启动器提供的信息。完整系统还应识别保留区和多个内存区，避免把设备地址、固件数据等当作可分配内存；直接向未知地址试写探测不适合作为通用方案。

### 实现结果

QEMU 运行时设备树报告的物理内存为 `[0x80000000, 0x88000000)`。本地验证输出显示：

```text
page descriptors: [0x0000000080207000, 0x0000000080347000)
free memory:     [0x0000000080347000, 0x0000000088000000), 31929 pages
check_alloc_page() succeeded!
```

这说明 Page 描述符数组已建立，描述符占用区域没有交给分配器，First-Fit 的基础分配/释放检查通过。

## 六、实验总结与收获

本模块体现了物理内存管理的基本关系：设备树提供硬件事实，`Page` 数组提供软件抽象，`pmm_manager` 则提供分配算法接口。物理地址和内核虚拟地址通过固定偏移转换；只有被 `init_memmap()` 注册的页面才会进入空闲链表。

后续报告需要补充 Best-Fit、Buddy System、QEMU 页表调试（如完成）以及各成员实际的 Prompt 迭代记录。

本模块对应 OS 原理中的“物理页框管理”和“启动时保留内存”：`Page` 是页框的软件描述，描述符本身也需要占用物理内存。固定偏移转换是内核直接映射的特殊情形，不等于所有虚拟地址都可以通过简单相减得到物理地址。本阶段没有实现进程独立地址空间、缺页处理、页面置换或并发分配同步。
